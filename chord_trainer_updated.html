How to use

  1. Choose which chord types and inversions to practise; use the staff visibility and microphone threshold controls as needed.
  2. Generate a random chord.
  3. Tap “Start listening” and allow microphone access.
  4. Play all the notes together and hold them briefly.
  5. The app will show detected notes and whether the chord matches.
For microphone access, open this file in Android Chrome. Some Android versions require a secure (HTTPS) page for microphone access; if Chrome blocks the microphone on a locally opened file, the app will need to be hosted on a secure website.
